# 《可计算理论》设计系统

## 视觉来源

本项目仿照同目录 `总纲_知识图谱演示`：保持温暖的羊皮纸背景、深蓝墨色、低饱和分类色、左侧粗色条节点、右侧详情卡，以及 900ms 的电影式相机移动。

## 核心 Token

| 语义 | Token | 色值 |
| --- | --- | --- |
| 全局背景 | `--bg` | `#D6BF88` |
| 节点纸张 | `--paper` | `#DED7CA` |
| 聚焦纸张 | `--paper-soft` | `#E9E2D3` |
| 主文字 | `--ink` | `#13254F` |
| 次文字 | `--ink-muted` | `#425D61` |
| 可计算性 / 判定 | `--blue` | `#163F6F` |
| 复杂度 / 验证 | `--teal` | `#396D80` |
| 边界 / 对角线 | `--plum` | `#624F6B` |
| 资源 / 警示 | `--ochre` | `#B5855F` |
| 高光 | `--cyan` | `#83D0E3` |

## 语义规则

- 蓝色表示停机保证、判定与可计算任务。
- 青色表示资源增长、验证与复杂度分类。
- 梅色表示自指、不可判定边界与限制。
- 赭色表示指数代价、资源条件与现实约束。
- 颜色必须同时配合标题、边标签或空间位置，不能作为唯一编码。

## 组件与运动

- 节点卡：16px 圆角，左侧 8px 语义色条，深蓝细边。
- 详情卡：固定在右侧，标题不超过两行，正文不超过 7 个视觉行。
- camera：`900ms cubic-bezier(.16, 1, .3, 1)`。
- 节点展开：520ms；收缩：420ms；关系线绘制：520ms。
- morph：1200ms，先保留来源结构，再移动映射节点，最后出现目标结构。
- 主舞台为 1600 × 900 世界坐标；演示画布为 16:9。
