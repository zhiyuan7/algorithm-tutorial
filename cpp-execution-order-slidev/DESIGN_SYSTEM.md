# Design System：Cpp——执行顺序

## 视觉目标

版式与“course-overview-slidev”保持一致：`Minimal / Academic / Technical / Cinematic`。暖黄背景承载持续的知识空间；米色节点与详情卡承载内容。镜头移动只表示讨论对象或分析尺度变化。

## 字体与尺度

- 中文主字体：`Microsoft YaHei`，回退到 `Noto Sans CJK SC`。
- 公式字体：`Cambria`、`Times New Roman`；代码字体：`Consolas`、等宽回退。
- 封面标题 66 px；场景标题 31 px；详情标题 33 px；详情核心句 21 px；解释 16 px；节点标题 24 px；注释 13 px。
- 16:9 画布。详情卡位于右侧，宽 482 px；长代码只在详情卡展示，概览节点只保留短标签。

## 知识层级与路径

- `overview`：全图形状和三个结构分支。
- `concept`：短标签与空间位置。
- `summary`：分支讲完后收缩为概括，节点仍留在地图中。
- `detail`：右侧面板显示例子、代码、公式和边界。
- 顺序分支是一条时间线；选择分支体现条件分流；循环分支增加标为“条件回跳”的反馈弧。后者不能被读成普通父子关系。

## 镜头与运动

| 动画 | 时长 | Easing | 语义 |
| --- | --- | --- | --- |
| Camera | 900 ms | `cubic-bezier(.16,1,.3,1)` | 焦点转移 |
| Expand | 520 ms | 同上 | 深入详情 |
| Collapse | 420 ms | ease | 回到分支摘要 |
| Appear | 320 ms | ease | 节点出现 |
| Edge Draw | 520 ms | 同上 | 新关系建立 |
| Graph Morph | 1200 ms | 同上 | 局部机制转为算法用途 |

`node` 镜头保留当前节点和祖先；`subtree` 展示整条分支；`all` 自动适配全图。详情场景将地图移至左侧，为右侧面板留空间。禁止无语义的弹跳、闪烁、旋转和反复脉冲。

## 两图过渡

图谱 A“控制下一步”与图谱 B“结构构造算法”在数据中独立。`ControlMorph.vue` 只展示三组语义映射：

- 顺序执行 → 外层顺序：初始化、处理、输出依次发生。
- 选择执行 → 分段函数：条件决定计算路径。
- 循环执行 → 有限求和：重复更新累积状态。

来源卡片沿轨道退场，目标卡片进入；下一拍以 B 的完整概览建立方位。过渡不创建跨图谱边。
