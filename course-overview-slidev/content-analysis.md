# 《总纲》内容分析

## 一、文章核心问题

文章实际上回答两个层次不同、但相互关联的问题：

1. 科学如何从复杂现实中形成模型与理论，又如何通过实验回到现实。
2. 形式科学与自然科学分别以什么作为起点，各自如何理解真理、有用性与知识边界。

因此演示需要两张独立知识图谱，而不是一张不断向下延伸的树。

## 二、第一张图谱：科学认识循环

### 一级节点

- 现实 `Reality`
- 第一座桥：归纳与建模 `Induction & Modeling`
- 理论 `Theory`
- 第二座桥：演绎与实验 `Deduction & Experiment`

### 主要关系

1. 现实经过问题切割、观测与抽象，进入建模。
2. 建模将观测量组织为可推理结构，并与一般理论相连。
3. 理论与具体模型共同推出可观测预测。
4. 实验结果回到现实，支持、限制或迫使修改假说。

### 适合公式与独立画面的内容

- 单目测距：`h/f = H/Z`，`Z = fH/h`。
- 单摆模型：`F = ma`，`θ̈ + (g/l)sinθ = 0`。
- 假说演绎：`H ⇒ P`，`¬P ⇒ ¬H`，`P ⇏ H`。
- YOLO 距离实验：1m 到 5m 的受控实验设计。

## 三、第二张图谱：科学的两种范式

### 形式科学分支

- 公理：形式系统要求接受的基本前提。
- 欧几里得五条公设：一套明确规则如何定义几何。
- 第五公设的独立性：通过满足 `Σ` 但违反 `P` 的模型说明 `Σ ⊬ P`。
- 哥德尔第一不完备定理：足够强的一致形式系统中存在不可判定命题。
- 哥德尔第二不完备定理：系统不能在自身内部完成对自身一致性的全部保证。

### 自然科学分支

- 理论需要具有现实意义，并接受经验检验。
- 形式体系可以成为自然科学的候选模型。
- 非欧几何从形式研究进入广义相对论，是“用与无用”讨论的核心案例。
- 可谬论将两种范式重新连回可修正的知识实践。

## 四、变形过渡的概念映射

变形仅用于帮助观众从第一张图的提问方式，转向第二张图的组织方式：

- 现实 + 归纳建模 → 自然科学。
- 理论 + 演绎 → 形式科学。
- “实验”的部分语义保留在自然科学，“演绎”的部分语义进入形式科学。

这是一个过渡镜头，不是声称两组概念严格等价。

## 五、内容准确性调整

演示保留原文主线，并对三处表述做了显式区分：

1. 一致性表示系统不推出矛盾，公理不能由其他公理推出则属于独立性，两者不是同一概念。
2. 原文单摆中间式 `θ̈ = -mg sinθ` 缺少力臂与转动惯量的处理。演示使用经典单摆结果 `θ̈ + (g/l)sinθ = 0`，避免将中间式当作严格推导。
3. 自然科学中的“公理”不简化成“经验上正确的公理”，而表述为理论和模型需要通过可观测预测接受检验。

## 六、压缩与保留原则

- 保留所有一级主题，不删除“用与无用”、哥德尔不完备性和可谬论。
- 希腊语词源压缩为公理节点的一句解释，不在主画面展开全部形态分析。
- 欧几里得公设的希腊原文不整段投屏，保留五条公设的概念功能。
- 庞加莱圆盘的完整度量构造保留在原文，演示聚焦反模型的逻辑作用。
