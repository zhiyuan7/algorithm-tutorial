# Design System

本项目沿用 `course-overview-slidev` 的暖黄、深蓝、纸面、学术式知识地图视觉。背景明确使用 `#D6BF88`；`#D7B662` 只用于小面积辅助。布局的具体坐标根据数学分析的三张独立概念图重新安排。

## 色彩 Token

| Token | 色值 | 数学分析中的语义 |
| --- | --- | --- |
| `--bg` | `#D6BF88` | 全部演示画布 |
| `--paper` | `#DED7CA` | 知识节点和细节面板 |
| `--paper-soft` | `#E9E2D3` | 当前聚焦节点 |
| `--ink` | `#13254F` | 主标题、公式 |
| `--ink-muted` | `#425D61` | 次级说明 |
| `--blue` | `#163F6F` | 极限、控制、主要关系 |
| `--teal` | `#396D80` | 连续、线性映射、Jacobian |
| `--sky` | `#74A0BA` | 数列、偏导、基本规则 |
| `--sage` | `#7D8981` | 次要关系 |
| `--green` | `#9AAE8F` | 向量与矩阵值线性化 |
| `--plum` | `#624F6B` | 导数、复结构、二阶变化 |
| `--wine` | `#644A56` | 反例、条件边界、逆矩阵 |
| `--ochre` | `#B5855F` | 计算与应用 |
| `--lavender` | `#ACA6BF` | Cauchy–Riemann 限制 |
| `--brown` | `#7D665C` | 脚注与页角 |

页面中的节点、面板与关系线均使用这些已记录的颜色，不在组件中随机产生色值。

## 字体与层级

- 中文：`Microsoft YaHei`，Linux 回退 `Noto Sans CJK SC`。
- 公式：`Cambria`，回退 `Times New Roman`。
- 封面主标题 66 px；场景标题 31 px；细节标题 33 px；细节结论 21 px；解释 16 px；节点标题约 21 px。
- 概览节点只给短标题；细节写入右侧 482 px 面板。公式允许分行，长推导放讲者备注或源文。

## 节点、边、镜头

- 左色条表示语义类别。当前节点强调，其余节点保留空间位置，帮助记忆。
- 实线表示定义、推出、扩展或计算；虚线表示反例边界与应用。每条边都写明关系。
- 三张图的数据各自独立：一元局部结构、方向与线性映射、矩阵微积分。
- `node` 镜头定位当前概念，`all` 镜头自动容纳整张图；右侧面板出现时，焦点移向左半画面。
- 一次 click 只改变一个主要讲述目标。概念变形分为来源保持、位置移动和目标关系出现三个状态。

## 动效

沿用总纲的 `cubic-bezier(.16,1,.3,1)`。镜头 900 ms、节点展开 520 ms、关系出现 520 ms；跨图变形 1200 ms。动画仅用于表示概念继承、方向扩展和矩阵化，不使用闪烁、弹跳或粒子。
