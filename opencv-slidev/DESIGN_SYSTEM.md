# Design System · OpenCV 知识图谱

## 参考与目标

直接参考 `course-overview-slidev` 的 `DESIGN_SYSTEM.md`、页面配置和组件样式。采用 Minimal / Academic / Technical / Cinematic 风格。主背景固定为暖黄 `#D6BF88`；纸色节点与详情面板、深蓝标题和低饱和语义色沿用总纲。

## 排版与层级

- 中文：`Microsoft YaHei`，回退 `Noto Sans CJK SC`；公式：`Cambria` / `Times New Roman`。
- 封面标题 66 px，图谱标题 31 px，节点标题 24 px，详情标题 30 px。
- 节点保持短标题；一层概要或解释进入右侧详情面板。
- 四种语义模式：overview、summary、concept、detail；同一节点 ID 跨点击保持稳定。

## 关系与运动

- 标签说明依赖、清理、测量或验证关系；连接线只在对应关系出现时显露。
- Camera 900 ms，节点展开 520 ms，出现 320 ms；过渡 1200 ms，统一 `cubic-bezier(.16,1,.3,1)`。
- 图谱使用独立数据对象。过渡组件根据 `morphGroups` 将“任务/信号/干扰”映射到处理选择；源图淡出后目标图出现。
- 主舞台持续存在，`$clicks` 每推进一次只进入一个叙事状态。结尾拉远回到完整处理图。

## 空间

- 16:9，SVG 世界坐标 1600×900；详情状态为右侧面板保留空间。
- 图谱节点按两行或三行网格布置。镜头由节点边界计算，不在 tour 中硬编码坐标。
- 16:9 浏览器画面需要检查节点、面板、公式和关系标签的裁切与重叠。
