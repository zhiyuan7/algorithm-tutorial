# 《可计算理论》内容分析与改编说明

原始材料保留在 `content/source.md`。演示按“算法的保证 → 求解与验证的代价 → 计算系统的能力”展开，教学文字与讲稿使用自然的问题承接，不在画面中使用“第一张知识图”等制作术语。

## 可计算性：先比较保证，再提出停机问题

可识别与可判定是并列讲解的两个概念，放在根问题下的同一层。层次结构组织讲解，虚线表达语言类的包含关系：

$$\mathrm{Decidable}\subsetneq\mathrm{Recognizable}.$$

先解释 YES 的单边保证，再解释 YES、NO 都停机的双边保证。这两个场景不提前引入具体难题；第二个场景不会出现接受问题或停机问题节点。

根据用户确认，之后以**停机问题**为主线：能否预先判断任意程序在给定输入上最终是否停机？这里使用现代教材中的停机问题表述，承接图灵关于计算与可判定性的工作；不把现代命名直接当成 1936 年论文原句。

$$\mathrm{HALT}_{\mathrm{TM}}=\{\langle M,w\rangle\mid M(w)\text{ 停机}\}.$$

模拟看到停机就接受，说明它可识别。等待本身不能证明永不停机，但这只提供直觉；正式的不可判定证明采用对角线法：假设总能正确预测的判定器 $H$，构造预测会停机就循环、预测不停机就停机的 $D$，再把 $D$ 自己的编码交给它。两种预测都会出错。

原文同时使用接受问题 $A_{TM}$ 的定义与停机问题的识别器。现在定义、模拟、对角线反转和最终边界均统一为停机问题。接受问题与停机问题并非同一语言；演示不再来回切换这两种定义。

## 复杂度：并列讲 P 与 NP，再进入 SAT 与开放问题

P 与 NP 在可判定任务下同层展示；虚线保留 $\mathrm P\subseteq\mathrm{NP}$ 的已知事实。讲解先并排介绍快速求解与快速验证，然后分别展开定义和例子。

- P：确定性多项式时间。固定次幂的例子与一次扫描找最大值保留；说明找最大值的判定版本属于 P。
- NP：强调证据长度有多项式上界，验证器的运行时间也受多项式限制。指数枚举并入这一场景，作为寻找证据的有限方法；删除单独的指数枚举节点和场景。
- SAT：放在 NP 下，引出 SAT 是 Satisfiability 的缩写，全称 Boolean Satisfiability，即布尔可满足性。先定义问题，再代入赋值验证。
- P 是否等于 NP：在 SAT 下承接“快速验证能否变成快速求解”。这种上下层是叙述顺序，不表示开放问题是 SAT 的子类。

NP 的多项式长度证据空间有限，可以枚举，因此 NP 都可判定。指数枚举不是 NP 的定义，也不证明 SAT 必须花指数时间。这里也避免把判定算法不存在与运行代价很大混为一谈。

$$\mathrm P\subseteq\mathrm{NP}\subseteq\mathrm{Decidable}.$$

## 图灵完备：模拟能力、存储与控制流

正式定义是能够模拟任意图灵机。普通命令式系统中的可扩展存储、条件分支和无固定上限循环或递归，作为直观构件解释。

条件分支与循环、递归合成同一个控制流节点与场景。无固定步骤上限不意味着所有程序都无限运行。按用户要求，删除演示中的阶乘节点、公式及示例；原始材料副本保留。

最终用停机问题说明：能表达所有可计算过程，不代表可以判定所有程序的停机行为。

## 分支展开与视角转换

- 讲解当前分支时，收起其他分支；仅保留必要的父节点或明确指定的关联节点。
- 相机依据实际可见节点拟合，详情场景留出右侧面板的安全区域。不以最低缩放值强行放大，避免高树形结构侵入面板。
- 回顾可计算性、复杂度和通用计算时恢复各自整图。
- 可计算性转向复杂度：可判定任务保留，P 与 NP 并排出现；停机问题留在右侧可判定范围之外。不可判定的分界不再画在 P 的下方。
- 复杂度转向图灵完备：求解、验证与 SAT 折叠成资源视角，再展开系统模拟能力。两次转场不把不同问题框架拼成一个层级。
- 实线沿用原来的平滑曲线；虚线改为带直角折点的路线，在卡片之间的空隙走线。
