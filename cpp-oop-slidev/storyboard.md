# 分镜：从对象到类型协作

同一个 KnowledgeStage 承载 25 个状态。以下编号对应舞台的进度编号，不计封面和结束页。讲解时只保留当前节点及其祖先路径；回顾时恢复分支或整图，镜头按可见节点边界取景。

| 编号 | 内容 | 讲述目标 |
|---:|---|---|
| 1 | 对象 | 让机器人自己管理状态和行为 |
| 2 | 构造 | 隐式默认构造、自定义构造，以及何时不再自动提供无参版本 |
| 3 | 初始化列表 | 直接构造与先构造再赋值的区别，避免额外工作 |
| 4 | 初始化要求 | const、引用、无默认构造成员和声明顺序 |
| 5 | 析构 | 离开作用域自动收尾 |
| 6 | RAII | 资源交给对象生命周期 |
| 7 | default / delete | 请求默认实现或禁止指定操作 |
| 8 | 封装 | 复用过程、控制接口两个原因 |
| 9 | 复用过程 | 检查和更新封装成取款流程 |
| 10 | 控制接口 | 稳定操作让内部实现容易扩展 |
| 11 | 封装回顾 | 恢复封装分支 |
| 12 | 对象回顾 | 恢复对象整图 |
| 13 | 类型协作 | 关系、函数声明和运行时行为 |
| 14 | 继承与组合 | 同页比较 is-a 与 has-a |
| 15 | 派生类能力 | 复用与扩展，尊重 private |
| 16 | 非虚函数 | 声明形式 |
| 17 | 虚函数 | virtual 和 override 的写法 |
| 18 | 纯虚函数 | = 0 与具体派生类实现 |
| 19 | 动态分派 | 基类接口调用不同对象 |
| 20 | 虚函数表与指针 | vptr、共享 vtable、实现入口的示意 |
| 21 | 虚调用过程 | 沿指针与表项找到对应函数 |
| 22 | 工厂 | 隐藏具体创建，unique_ptr 管理生命周期 |
| 23 | 虚析构 | 通过基类指针完整销毁 |
| 24 | 构造与析构顺序 | 先基类构造，先派生类析构 |
| 25 | 类型协作回顾 | 恢复类型整图 |

原进度第 13、14 步（视角转换、概念变形）已删除。组合不再作为独立节点或讲述状态；函数契约是继承的子节点；虚函数表与指针归在动态分派下。
