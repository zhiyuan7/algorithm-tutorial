# Design System · 相机模型

沿用《总纲_知识图谱演示》的 Minimal / Academic / Technical / Cinematic 体系。暖黄画布 `#D6BF88` 是唯一主背景。纸面节点 `#DED7CA`，主文字 `#13254F`。语义色从总纲原有 token 选用：几何 `#163F6F`、畸变/光学 `#396D80`、标定约束 `#624F6B`、求解与验证 `#B5855F`、颜色采样 `#7D8981`、颜色重建 `#9AAE8F`。不按 RGB 字面做大片红绿蓝装饰。

CSS token 与总纲一致；关系用实线表示连续流程、虚线表示约束或验证，标签写明关系。标题 31px，节点 24px，详情标题 33px，详情正文 21/16px。中文优先 Microsoft YaHei / Noto Sans CJK SC，公式优先 Cambria。一个点击推进一个内容或镜头节拍。

持续舞台的镜头时长 900ms，节点展开 520ms，边绘制 520ms，图谱变形 1200ms，缓动 `cubic-bezier(.16,1,.3,1)`。详情面板在右侧；镜头避开面板并保留邻接节点。所有场景按 1600×900 的 16:9 画面设计。
