# 《简明机器人学》内容分析

## 核心问题与结论

**问题：**怎样无歧义地描述刚体运动，并从关节变量求末端位姿？

**论证：**先区分几何对象、相对参考系和表达坐标系；再以 `SO(3)` 和 `SE(3)` 组织旋转与位姿；轴角、螺旋和欧拉角提供不同参数化；最终用 DH 的局部换系链或 PoE 的统一空间螺旋轴求正运动学。

## 图谱边界

1. **表示图**回答“运动是什么、用什么坐标记、怎样变换”。四个核心节点为坐标语义、`SO(3)`、`SE(3)`、紧凑表示。关系表示依赖、推广和参数化。
2. **求解图**回答“已知关节变量，怎样算末端位姿”。根节点为正运动学，分支为 DH、PoE、末端位姿。边表示计算方法及目标。

第二图不能只是第一图的更多子节点：它把静态的表示工具转为机械臂求解过程。两图独立建模，用显式 morph 对应：坐标语义 → DH 坐标系链，`SO(3)` → 关节旋转，`SE(3)` → 末端位姿，螺旋表示 → PoE 螺旋轴。

## 呈现中的技术澄清

- 原文说齐次矩阵可作用于“点、向量或者坐标系”。演示明确：点的齐次末项是 `1`，自由向量是 `0`，因此平移只影响点。原文不改。
- 速度记号里把“相对参考系”和“表达坐标系”分开；运输定理中的导数是在两个不同转动参考系中观察同一向量，不把换基误解为真实运动。
- `R = exp([ω̂]θ)` 采用单位轴；`S` 用于旋转关节时也按单位螺旋轴约定，移动关节可令角速度部分为零。
